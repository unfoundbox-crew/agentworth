02 — Accent

Violet — one accent, and only where it's earned

AgentWorth's identity color. It carries selection, focus, links, and the receipt's total line — nothing else. Chart series and status use their own tokens below, deliberately kept out of this family.

--mv-accent
#7c6bb3 · #a396d6
--mv-accent-soft
rgba violet 8% / 10%
--mv-accent-border
rgba violet 28% / 30%
Aa
--mv-accent-contrast
text/icons on solid accent

The accent gets lighter in dark (#7c6bb3 → #a396d6) — a saturated violet that reads on white goes muddy on true black, so lightness rises to keep it legible and keep it looking like the same color.

05 — Source

Where these live
