02 — The contract

Three states, three places, always this order

  1. Bare :root — the complete light palette. No dark override present. A crawler, a screenshot tool, or a browser with no media-query support renders light, correctly, not by accident.
  2. @media (prefers-color-scheme: dark), guarded by :root:not([data-theme="light"]) — applies only when the OS prefers dark and the viewer hasn't explicitly forced light.
  3. :root[data-theme="dark"], unguarded — the same dark values a third time, so an explicit Dark choice wins even on a light-mode OS.

The rule that keeps this from breaking: a token never gets its only definition inside a media query or a [data-theme] block. Every custom property is declared on bare :root first — the other two blocks only override it.

03 — Persistence

The toggle writes to localStorage

Key: agentworth_theme in the shipped apps (this preview bundle uses its own agentworth-ds-card-theme key so it never collides with a real app's storage). "system" removes the data-theme attribute entirely rather than writing "system" onto it — that's what lets the guarded media query decide.

function applyThemeToDocument(theme) { const isDark = theme === 'dark' || (theme === 'system' && matchMedia('(prefers-color-scheme: dark)').matches); document.documentElement.classList.toggle('dark', isDark); // Tailwind dark: utilities if (theme === 'light' || theme === 'dark') { document.documentElement.setAttribute('data-theme', theme); } else { document.documentElement.removeAttribute('data-theme'); } }
04 — Hard rule

Light is the default

The bare :root palette is light, full stop. Dark is the override, defined in the two guarded blocks — never the other way around. Every card in this bundle ships the same visible toggle; none goes out without it.
