ASCII / box-drawing conventions

The exact glyph set, role colors, and evidence meter the CLI renders every screen through.

01 — The allowed glyph set

Nothing outside this list, ever

Verbatim from apps/cli/src/ui/mod.rs's own header comment — the CLI enforces this with a test (no_output_glyph_falls_outside_the_allowed_set).

No emoji, ever. Geist Mono and SF Mono both lack ⛰ ⛳ ◉ ✓ ✗ — a missing glyph silently falls back to a different face at a different advance width and shifts every column to its right. That's why the set is this narrow.

Violet has no ANSI-16 equivalent; magenta is the honest substitute rather than a made-up mapping. NO_COLOR, --no-color, --plain, or a non-TTY stdout all resolve to no color at all — the meter and rules still read correctly because filled cells come first.

03 — The evidence meter

Five cells, filled first

●●●○○ rung 3 of 5 ##... same meter, NO_COLOR / --plain / piped output

ASCII mode turns on by itself when stdout is not a TTY — a piped or redirected stream carries no glyph a downstream tool has to guess the width of. Color and glyph mode vary independently; a plain terminal with truecolor still gets Unicode dots, colored.
