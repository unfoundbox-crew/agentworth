03 — Rules applied

Why this palette

Sequential, one hueMagnitude across an ordered rung, not identity — never a rainbow
Direct value labelsFive bars is few enough to label every one, no legend needed for a single series
Rounded, thin track4-5px radius, 20px bar height — matches the mini-table's row rhythm
Hover title on each fillNative tooltip; a full custom tooltip is overkill for a 5-bar chart
