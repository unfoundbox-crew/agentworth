01 — The chart

Token spend across one session's turns

A single series, so no legend box is needed — the title names it. The area under the line is a soft accent fill; the line itself stays 2px, the endpoint gets a filled dot per the dataviz skill's mark spec.

Latest turn102K tokens

Each turn carries an invisible, larger hit target (a transparent circle, r=9) with a native <title> tooltip — hover any point above to read its value. Production would swap this for the shared crosshair+tooltip component; this preview keeps it to native SVG so the card has no script dependency.

02 — When to reach for this

Use it for

A single session's shape over time — token spend per turn, latency per call — inside a session row or the inspector. Not for comparing sessions; that's token-turn-exposure-area.html's job (stacked, multi-session).
