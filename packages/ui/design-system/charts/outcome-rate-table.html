Outcome rate table

Adapter outcome rates that always carry their sample size — and go quiet below a confidence floor instead of lying with a bar.

01 — The table

Outcome rate by adapter, with an n floor

A rate with no sample size is a rumor. Every row carries its n in the same mono column as the rate; below the floor (n<10 in this system), the rate itself is suppressed rather than shown with false confidence — same principle as the CLI's "never print a zero for an adapter that keeps no token counts."

The floor is not decorative

n ≥ 10Rate shown, bar drawn, one accent fill
n < 10Rate suppressed, n shown in --mv-danger text — a fact about confidence, not a bad outcome
n = 0Row omitted entirely — nothing to floor
