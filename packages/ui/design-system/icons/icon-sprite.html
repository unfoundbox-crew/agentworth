The receipt mark

BrandMark

Two neutral line items over one heavier violet bar — the total, the number that got checked. Inlined as packages/ui/BrandMark.tsx with --mv-ink / --mv-accent fills, so it never needs a separate -dark file. Clear space: one line-item bar height (1/8 of the mark) on every side.

05 — Usage rule

One glyph, one meaning, one grid per surface

RuleWhy
No emoji, anywheredesign.md hard rule 3 — number sections with mono eyebrows instead
Never mix the 20x20 round-cap and 24x24 square-cap grids on one screenDifferent constructions read as two different products
Multi-color brand marks keep their real hexA recolored Gemini or Qwen mark stops being recognizable
Everything else is currentColorFollows text color in both themes for free
16 / 20 / 24px are the only sizes shippedMatches the dashboard's rail, list-row, and inline-text contexts
