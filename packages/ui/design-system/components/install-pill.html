02 — Rule

The one inverted surface

This pill is the single place in the marketing site where --mv-ink fills a shape instead of coloring text — reserved for the one action the whole page exists to drive. In dark mode it switches to --mv-surface-3 rather than staying pure ink-on-ground, so it still reads as "raised," not as another black rectangle on black.
