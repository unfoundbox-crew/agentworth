01 — The component

Session row, with a compaction badge

One row per session in the list pane. A live session gets a pulsing --mv-success dot (see the top bar's livetail indicator, same recipe). A compaction badge appears only when the session's history was actually compacted — it counts, so "×2" means two compaction events, not a boolean flag.

02 — Badge rule

Warn color, not danger

Compaction is normal operation for a long session, not a problem — it gets --mv-warn (the same "something happened, pay attention" tone as a cache cold start), never --mv-danger. A session with zero compactions shows no badge at all rather than a "0" badge.
